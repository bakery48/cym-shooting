## 1. 混色の敵

CMY は減法混色なので、2色重ねると RGB になる。

| 状態 | インク | 必要弾数 | 一方向回転での最短回転数 |
|---|---|---|---|
| シアン | C | 1 | 0 |
| マゼンタ | M | 1 | 0 |
| イエロー | Y | 1 | 0 |
| 青 | C+M | 2 | 1 |
| 緑 | C+Y | 2 | 1 |
| 赤 | M+Y | 2 | 1 |
| 黒 | C+M+Y | 3 | 2 |
| 白 | なし | ― | ― |

**難度が色の理屈からそのまま出てくる。** 単色は回転不要、2色は1回転、黒は2回転。
恣意的な数値ではなく色の構造が梯子になっているのが、この案の一番強いところ。

### 実装は3ビットで足りる

```js
const C = 1, M = 2, Y = 4;      // enemy.inks に 0〜7 を持つ
enemy.inks &= ~bullet.ink;      // 撃たれたインクを剥がす
if (enemy.inks === 0) kill();   // 全部剥がれたら撃破
```

色は `inks` から引くだけなので、状態と見た目が二重管理にならない。
**撃つ順番は問わない**（赤にMを当てれば黄、Yを当てればマゼンタ）ので、
プレイヤーは回転距離の近いほうを選べる ― 判断が増えて、理不尽にはならない。

### 残っている課題 ― 外れ弾の扱い

**これだけ未決定のまま。決まるまでは従来どおり「弾かれる」。**

減法混色なら、乗っていない色を当てたとき**インクが増える**ほうが自然
（赤 + シアン = 黒）。誤射が敵を強化するので緊張感は跳ね上がるが、罰としては重い。
また「増える」を採ると、白い敵（インクなし）が撃つほど強くなり、
「下位の敵」という位置づけと噛み合わなくなる ― そこの扱いも同時に決める必要がある。

`js/game/update.js` の `resolveBulletHit()` にコメントで印を付けてある。

### 解決したもの

- 白い敵 → 素地（インクなし）として整理。剥がすものが無いので一発で割れる
- 装甲 → インクとは別の軸として維持。ポッドの弾を弾く役だけを担い、HPの概念は
  インクの本数に吸収された
- 黒が背景に沈む → 縁を描いて浮かせた（コントラスト比 1.20）

### 経済への影響（見落としやすい）

**ポッド1基では2色以上の敵を倒しきれない。** マゼンタのポッドは赤をイエローにするだけで、
仕上げには別の色が要る。つまり**ポッドの価値が非線形**になり、
3基そろって初めて自動化が完成する。
現在の価格（150 / 260 / 400）は価値が線形である前提なので、**組み直しが要る。**

## 2. 弾種の段階解放

ステージ1-1 はマゼンタのみ。徐々にシアンが開き、ステージ2あたりで CMY が揃う。

導入としては良い。1色のうちは回転そのものが存在しないので、
**移動と射撃を覚えてから、回転という動詞が後から増える**形になる。

### 実装した内容

面は 1-1 / 1-2 / 1-3 / 2-1 / 2-2 / 2-3 ＋モード2つ。
1-1 はマゼンタのみ、1-2 でシアン、1-3 で三色そろう。
砲塔のバレルの本数は使える色の数と一致し、1色の面では回転そのものが無い。

- **解けない敵を出さない。** その面で撃てないインクを含む敵が出たら詰む。
  面ごとの敵構成は「使えるインクの部分集合」に限る必要があり、
  `validateStages()` が全面を検査する。実際にこの検査が
  「1-1 で撃てない色のポッドが買える」という不具合を実装中に見つけた。
  ショップの品揃えは面ごとの手書きをやめ、解放済みインクから機械的に絞っている
- 2色の間は、一方向回転でも毎タップ必ず切り替わるので**切り替えコストが実質ゼロ**。
  企画書 §3 の緊張が効き始めるのは3色そろってから。ここは段階として意図的に受け入れる
- 砲塔の3連バレルは、未解放ぶんを暗く描いて残すか、本数自体を増やしていくか
- 面の番号が「1-1」形式になるなら、現在の「第1区〜第6区」の構成を組み直すことになる

## 3. 形の統一と、挙動による差別化

敵の形をすべて同じにして、色だけで区別する。代わりに挙動で差をつける
（木の葉のようにひらひら落ちる敵、ゆっくり横移動して弾を避ける敵）。

### 実装した内容 ― 模様で冗長性を戻した

**形をなくすと、色が唯一の情報チャネルになる。**
現在は形（●▲■）と色が同じ情報を二重に持っていて、片方が読めなくても遊べる。
形を統一し、さらに赤・緑を足すと、**色覚特性のあるプレイヤーが遊べなくなる**。
赤と緑の区別は最も頻度の高い色覚特性で、Steam ではレビュー評価に直結する。

**採用: 形ではなく「塗りの模様」で冗長性を戻した。**

| インク | 模様 |
|---|---|
| C | 横線 |
| M | 縦線 |
| Y | 点 |

混色は模様が重なる（赤 = 縦線＋点、黒 = 全部）。
形は統一したまま冗長なチャネルが戻り、しかも
**「何色が混ざっているか」が模様の重なりとして直接見える** ―
混色そのものの可読性にも効く。形を揃えたいという意図とも衝突しない。

### そのほか

- **回避する敵とポッドの相性は未調整。** ポッドは現在位置に直線で撃つので、
  避ける敵に対して外し続ける。偏差撃ちを入れるか、外れるのを許容するかは
  実プレイで決める
- 挙動 × インク（7種）の組み合わせが増えるので、面ごとに使う組を絞っている

## 4. 敵のタイプ（2026-09-05 検討）

### いまの構成

敵は3つの軸の組み合わせでできている。

| 軸 | 値 | 担っている負荷 |
|---|---|---|
| `inks` | 8通り（素地・単色3・2色3・黒） | **照合** |
| `armored` | 有無 | **自動化への干渉**（ポッドの弾を弾く） |
| `motion` | drift / leaf / dodge | **位置取り** |

組み合わせの数は足りているのに手応えが薄いのは、**役割の軸が `armored` ひとつしかない**ため。

### 足すときの基準

混色でパニックになった件（頭が追いつかない）から、**足すべきは「読む量」ではなく
「どこにいるか・いつ撃つか」の判断**。企画書 §1 の「思考負荷は低く、
手数と時間の配分がプレイの中身」に沿うのはこちら側だけ。

実装は `motion` と同じ形にする ― 敵に `role` を持たせ、面ごとに重みで出現比を決める。
そうすれば面ごとに使う組を絞れて、全部いっぺんに降ってこない。

### 候補（効くと思う順）

#### 1. 妨害役 ― 自動化を止めてくる

生きているあいだ、自分と同じ色のポッドを黙らせる。妨害中はその敵とポッドのあいだに
線が引かれ、ポッドは暗くなる。

- **判断**: 手を止めて先に潰すか、自動化が減ったまま耐えるか
- **なぜ効くか**: 企画書 §2 のコアループは「ポッドを買う → 手が空く」。
  いまその獲得は一度買えば永久に安全で、**守る対象になっていない**。
  これは自動化に敵対者を与える案で、弧そのものを強くする
- 読む負荷はほぼゼロ（線が「今これを失っている」と直接示す）
- 装甲とは併存させない。ポッドを止めながらポッドで倒せないのは重すぎる

#### 2. 分裂 ― 倒す高さが判断になる 【実装済み】

撃破すると、その場で小さな**素地（白）の敵2体**に割れて落ち続ける。

- **判断**: 高いうちに割って破片を処理する時間を作るか、低い位置で割って突破を許すか
- **なぜ効くか**: 純粋に「いつ撃つか」だけの判断で、読む負荷が増えない
- 破片は素地なのでどの色でも落とせる（照合の負荷を足さない）

#### 3. 群れ ― 位置取りだけを問う 【実装済み】

同じ色の敵が3〜5体、固まって同時に湧く。

- **判断**: どこに立つか。1体ずつ追うと間に合わない
- 全部同じ色なので、**照合の負荷はむしろ下がる**
- 実装は最も安い（湧きを1回でN体にするだけ）

#### 4. 急降下 ― いつ撃つかを問う

ゆっくり落ちてくるが、途中から急加速する。加速の直前に予備動作を出す。

- **判断**: 遅いうちに撃つか、他を優先して後で慌てるか
- 予備動作が無いと理不尽になるので、そこは必須

#### 5. 運び屋 ― 優先順位を問う

報酬が高い代わりに、突破されると突破カウントが2進む。見た目で分かるようにする。

- **判断**: 他を捨ててでもこれを落とすか
- 実装は最も安い部類

### 採らない案

**塗り直し**（剥がした色を時間経過で塗り直してくる）は入れない。
遅いプレイを罰する強さはあるが、**「剥がす順番を問わない」という寛容さを壊す**。
この寛容さが照合の負荷を低く保っている当のものなので、パニックの件のあとで
これを削るのは筋が悪い。

### 実装するときの注意

- `role` × `inks`（8）× `motion`（3）で組み合わせが増えるので、
  面ごとに使う役割を絞る運用は必須
- 妨害役は装甲と排他にする
- 分裂は黒（3発）と重なると重い。終盤の面に限るか、黒とは排他にする
