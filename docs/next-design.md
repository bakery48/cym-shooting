## 1. 混色の敵

CMY は減法混色なので、2色重ねると RGB になる。

| 状態 | インク | 必要弾数 | 一方向回転での最短回転数 |
|---|---|---|---|
| シアン | C | 1 | 0 |
| マゼンタ | M | 1 | 0 |
| イエロー | Y | 1 | 0 |
| 青 | C+M | 2 | 1 |
| 緑 | C+Y | 2 | 1 |
| 赤 | M+Y | 2 | 1 |
| 黒 | C+M+Y | 3 | 2 |
| 白 | なし | ― | ― |

**難度が色の理屈からそのまま出てくる。** 単色は回転不要、2色は1回転、黒は2回転。
恣意的な数値ではなく色の構造が梯子になっているのが、この案の一番強いところ。

### 実装は3ビットで足りる

```js
const C = 1, M = 2, Y = 4;      // enemy.inks に 0〜7 を持つ
enemy.inks &= ~bullet.ink;      // 撃たれたインクを剥がす
if (enemy.inks === 0) kill();   // 全部剥がれたら撃破
```

色は `inks` から引くだけなので、状態と見た目が二重管理にならない。
**撃つ順番は問わない**（赤にMを当てれば黄、Yを当てればマゼンタ）ので、
プレイヤーは回転距離の近いほうを選べる ― 判断が増えて、理不尽にはならない。

### 決めること

- **外れた弾をどう扱うか。** 現状は弾かれる。しかし減法混色なら
  **「インクが増える」**が自然（赤 + シアン = 黒）。誤射が敵を強化するのは
  緊張感が跳ね上がるが、罰として重い。**どちらにするか先に決める。**
  なお「増える」を採ると、後述の白い敵（インクなし）と噛み合わなくなる
- **白い ◆ をどうするか。** 現在は「色を持たない＝どの弾でも壊せる」。
  減法混色では白＝素地なので「剥がすインクが無いから1発で割れる」と読み替えれば
  筋は通る。ただし形を統一するなら ◆ ではなくなる
- **装甲（ポッドの弾を弾く）と混色を併存させるか。** 7状態 × 装甲有無 = 14通りになる。
  多すぎるなら装甲を落とす判断もある
- **黒の敵が背景（`#232a45`）に沈む。** 明るい縁か輪郭が要る

### 経済への影響（見落としやすい）

**ポッド1基では2色以上の敵を倒しきれない。** マゼンタのポッドは赤をイエローにするだけで、
仕上げには別の色が要る。つまり**ポッドの価値が非線形**になり、
3基そろって初めて自動化が完成する。
現在の価格（150 / 260 / 400）は価値が線形である前提なので、**組み直しが要る。**

## 2. 弾種の段階解放

ステージ1-1 はマゼンタのみ。徐々にシアンが開き、ステージ2あたりで CMY が揃う。

導入としては良い。1色のうちは回転そのものが存在しないので、
**移動と射撃を覚えてから、回転という動詞が後から増える**形になる。

### 決めること

- **解けない敵を出さない。** その面で撃てないインクを含む敵が出たら詰む。
  面ごとの敵構成は「使えるインクの部分集合」に限る必要があり、
  これは自動で検査できる（実装時にテストを書く）
- 2色の間は、一方向回転でも毎タップ必ず切り替わるので**切り替えコストが実質ゼロ**。
  企画書 §3 の緊張が効き始めるのは3色そろってから。ここは段階として意図的に受け入れる
- 砲塔の3連バレルは、未解放ぶんを暗く描いて残すか、本数自体を増やしていくか
- 面の番号が「1-1」形式になるなら、現在の「第1区〜第6区」の構成を組み直すことになる

## 3. 形の統一と、挙動による差別化

敵の形をすべて同じにして、色だけで区別する。代わりに挙動で差をつける
（木の葉のようにひらひら落ちる敵、ゆっくり横移動して弾を避ける敵）。

### 決めること ― これが最大の問題

**形をなくすと、色が唯一の情報チャネルになる。**
現在は形（●▲■）と色が同じ情報を二重に持っていて、片方が読めなくても遊べる。
形を統一し、さらに赤・緑を足すと、**色覚特性のあるプレイヤーが遊べなくなる**。
赤と緑の区別は最も頻度の高い色覚特性で、Steam ではレビュー評価に直結する。

**対案: 形ではなく「塗りの模様」で冗長性を戻す。**

| インク | 模様 |
|---|---|
| C | 横線 |
| M | 縦線 |
| Y | 点 |

混色は模様が重なる（赤 = 縦線＋点、黒 = 全部）。
形は統一したまま冗長なチャネルが戻り、しかも
**「何色が混ざっているか」が模様の重なりとして直接見える** ―
混色そのものの可読性にも効く。形を揃えたいという意図とも衝突しない。

### そのほか

- **回避する敵とポッドの相性。** ポッドは現在位置に直線で撃つので、
  避ける敵に対して外し続ける。偏差撃ちを入れるか、外れるのを許容するか
- ひらひら落ちる敵は横方向の正弦運動で足りる。突破判定とポッドの狙いには影響する
- 挙動 × インク（7種）の組み合わせが増えるので、面ごとに使う組を絞る運用が要る
